# Навыки AZIRAL для Remotion

Авторский рабочий процесс для промороликов приложений: одно действие продукта, раскадровка по кадрам, адаптация композиции под формат и локальная визуальная проверка.

![AZIRAL REACT VIDEO](assets/cover.svg)

Автор: [Олжас Азирали / AZIRAL](https://aziral.com/olzhas-azirali). Это независимый проект, не связанный с командой Remotion и не одобренный ею. Название репозитория обозначает движок, с которым работает навык.

[English version](README.md)

## Установка навыка

```bash
npx skills add azirali/remotion --skill aziral-remotion-promo
```

Установка добавляет инструкции для совместимого ИИ-агента. Движок Remotion устанавливается отдельно по [официальной документации](https://www.remotion.dev/docs/). Можно использовать существующий проект Remotion.

## Пример запроса

```text
Используй $aziral-remotion-promo в моём проекте Remotion.
Сделай ролик на 12 секунд с демонстрацией одного полезного действия приложения.
Подготовь отдельные версии на русском, английском и казахском в форматах 9:16 и 16:9.
Используй предоставленные мной факты о продукте и скриншоты.
Открой локальный просмотр, проверь важные кадры и экспортируй MP4.
```

[examples/promo/brief.json](examples/promo/brief.json) содержит пример брифа для вымышленного приложения заметок: 30 кадров в секунду, три сцены и три формата. Это данные для планирования, которые агент адаптирует к проекту.

## Что даёт навык

- Раскадровку с целочисленными кадрами и понятным действием продукта.
- Отдельные тексты RU/EN/KK, проверку шрифта и времени чтения.
- Адаптацию расположения элементов для вертикального, горизонтального и квадратного форматов.
- Проверку установленного CLI перед выполнением команд.
- Локальный просмотр, проверку отдельных кадров и готового экспортированного файла.

Основные инструкции и справочные материалы: [skills/aziral-remotion-promo](skills/aziral-remotion-promo).
